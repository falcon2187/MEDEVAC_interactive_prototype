Human–AI interaction model

  1. Information agents provide source-labeled inputs.
  2. Planning agent organizes a review packet and flags uncertainty.
  3. Human reviews, questions, corrects, or requests revision.
  4. Human selects a disposition; system shows the resulting state.
  5. New reports trigger review and acknowledgment workflow.

Milestone 5 requirements represented

  • System and individual-agent status
  • Attention flags, uncertainty, and source conflicts
  • Human modification, approval-style disposition, rejection, and override workflow
  • Feedback and previous actions/outcomes
  • Interactive screens supporting M4 tasks for Milestone 6 testing

Milestone 6 evaluation tasks suggested by M4 p. 7

  1. Detect an incorrect AI casualty summary and correct it.
  2. Identify conflicting or stale agent information.
  3. Distinguish a draft recommendation from a human decision state.
  4. Submit a mid-mission update and verify acknowledgment.
  5. Identify a previous version and determine whether an edit overwrote it.

Suggested measures from M4: missed errors, decision time, number of corrections, and communication acknowledgment.
